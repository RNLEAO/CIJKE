## 轻量屏幕手动入口

上电后屏幕直接显示 `NP BENCH`。P73选择项目，P72执行操作：

1. 选择 `EN` 并按P72，使模块进入使能状态。
2. 选择 `ARM` 并按P72，完成布防。
3. 选择 `FIRE` 并按P72，风扇先以45%启动1秒，再以40%维持5秒。
4. 页面显示 `WAIT` 时等待冷却结束。
5. 选择 `RESET` 并按P72；复位成功后显示 `READY`。
6. 再次执行 `ARM → FIRE`，开始下一次测试。

一次触发结束后 `ARM` 自动变为 `OFF`，属于防止重复启动的安全行为。

## 安全逻辑

P33实际输出必须同时满足：

- 模块已经使能
- 模块已经布防
- 收到一次有效的 `FIRE` 请求
- 行走状态 `pwm_state == 0`
- 未处于故障、冷却或锁定状态
- 状态机处于 `PREPARE` 或 `HOLD`

任意条件失效时，P33占空比立即归零。
